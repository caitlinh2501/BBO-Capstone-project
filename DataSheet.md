Motivation 

The purpose of this datasheet is to support a sequential BBO tasks involving 8 unknown functions. 
The aim of the project is to identify inputs that maximise each function while working with limited expensive queries. 

The underlaying function is unknown - each new datapoint had to be generated by submitting an input vector and recieving the function value. 
This dataset has therefore grown throughout the project. 
The purpose of the dataset is to support surrogate modelling and Bayesian optimisation. 
In particular, the accumulated observations were used the fit the GP models. estimate promising regions and select the next query for each function. 
The dataset also supports analysis of how optimisation decisions change over time. 

Composition 
The dataset contain observed input and output pairs for 8 functions. 
The data are stored as NumPy arrays, with separate input and output files for each function. 
Inputs are stored as two-dimensional arrays of shape, while outputs are stored as one-dimensional arrays containing the corresponding objective values. 
There are no missing values within individual observations. However, the dataset is intentionally sparse relative to the size of each continuous search space. 
This is particularly important for the higher-dimensional functions, where only a very small proportion of the possible domain has been explored.

Collection Process 
The dataset was generated sequentially over the duration of the project. 
One new query was added per week. 
Candidate inputs where generated using a mix of local sampling around the best area, wider searches around promising regions and global candidate sampling for comparison. 
This was important when the model showed poor calibration. 
For example, some functions produced observations several predicted standard deviations away from the GP mean. 
In these cases, later searches were made more conservative rather than assuming that the model uncertainty was fully reliable.

Preprocessing and transformations
Most functions were modelled directly using their observed objective values, with output normalisation performed internally by the Gaussian Process model.
There were two exceptions.
For Function 1, the objective values were extremely close to zero in the best-performing region while some other observations were much more negative. 
A positive linear scaling was therefore applied. 

For Function 5, outputs were manually standardised before fitting the Gaussian Process. Predictions were converted back to the original scale for interpretation.
Input variables were already constrained to [0,1], so no additional input scaling was required.

Intended uses

The dataset is intended for:

Fitting and evaluating surrogate models for black-box optimisation;
Reproducing the optimisation decisions made during the project;
Studying sequential Bayesian optimisation behaviour;
Examining exploration versus exploitation decisions;
Analysing GP uncertainty and calibration;
Comparing observed and predicted function values;
Reflecting on the consequences of adaptive data collection.

Distribution and maintenance

The dataset was created for the Imperial College London machine learning and artificial intelligence capstone project and is maintained by the project author - Caitlin Hale.
The working data are stored locally as NumPy .npy files, separated by function, with cumulative input and output arrays updated after each optimisation round.
The dataset is primarily intended for assessment, reproducibility and analysis within the capstone project. 
It should not be redistributed publicly unless this is permitted by the course rules and the terms under which the black-box optimisation task was provided.
